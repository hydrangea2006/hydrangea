# Hydrangea OS

> 一个基于RICS-V架构的实验性类unix系统（本科毕业项目，大概)

## 📚项目简介
Hydrangea 是一个从零开始编写的类Unix系统，这个项目是本人从大二刚开始接触计算机组成与计算机系统时便想尝试的项目，关于计算机系统的各种活动，感觉都是很有意思的东西，所以趁着现在大三开始准备，看下大三大四穿插着考研能不能完成并作为毕业项目，如果不能，应该我也会继续完成，如果能完成，看下能不能迁移到x86-64上，当然这都是后话了

## 🛠技术栈与开发环境
- **指令集架构**: RISC-V
- **硬件抽象层**: OpenSBI (运行于 M-Mode)
- **运行环境**: QEMU
- **编程语言**: C语言/RISC-V汇编
- **构建工具**: GNU Make (交叉工具链 `riscv64-unknown-elf-gcc`)

## 🚀核心功能计划(roadmap)
- 启动与初始化
- 物理内存管理
- 虚拟内存与页表
- 陷阱与中断
- 进程管理
- 锁与同步
- 系统调用
- 控制台与uart
- 构建脚本完善

## 📂 目录结构规划

*(注:随着代码添加可能有所补充,但现在先做初步规划)*
```text
hydrangea/
|-- kernel/  # 内核核心代码
|  |-- arch/ # 架构相关 (启动汇编,链接脚本)

```
